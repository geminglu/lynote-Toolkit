# Cron 表达式生成器

一个浏览器本地运行的 7 字段 Cron 可视化生成与解析工具。它面向需要快速配置定时任务的人：既可以通过中文 UI 逐项选择秒、分、时、日、月、周、年并生成表达式，也可以把已有 Cron 表达式粘贴进来解析并回显到界面。

## 表达式格式

默认使用 Quartz 风格的 7 字段格式：

```text
秒 分 时 日 月 周 年
```

示例：

```text
0 30 9 ? * 2-6 *
```

对应描述：

```text
每年每月周一至周五 09:30:00 执行
```

## 主要功能

- 通过中文字段控件生成 Cron 表达式。
- 支持表达式解析，解析成功后会同步回显到左侧 UI。
- 自动生成简体中文可读描述。
- 支持 6 字段输入，解析时会自动补全年字段 `*`。
- 支持日字段和周字段互斥生成，自动处理 Quartz 风格的 `?`。
- 支持复制当前生成的 Cron 表达式。
- 不保存历史、收藏、localStorage、Dexie 或分享链接，数据只存在当前页面会话中。

## 字段说明

| 字段 | 取值范围           | 说明                                                       |
| ---- | ------------------ | ---------------------------------------------------------- |
| 秒   | `0-59`             | 控制触发秒数                                               |
| 分   | `0-59`             | 控制触发分钟                                               |
| 时   | `0-23`             | 控制触发小时                                               |
| 日   | `1-31` 或 `?`      | 按日期触发时使用；按星期触发时自动为 `?`                   |
| 月   | `1-12`             | 控制触发月份                                               |
| 周   | `1-7` 或 `?`       | `1` 表示周日，`2-7` 表示周一到周六；按日期触发时自动为 `?` |
| 年   | `1970-2099` 或 `*` | 控制触发年份，默认全年                                     |

## 字段模式

每个可配置字段支持四种常用模式：

- 每一：生成 `*`，表示该字段每个取值都匹配。
- 周期：生成 `起始值/间隔`，例如 `0/5` 表示从 0 开始每 5 个单位触发。
- 指定：生成列表，例如 `0,15,30,45`。
- 范围：生成范围，例如 `1-5`。
- 除年份外，范围允许跨边界，例如小时 `22-2`、月份 `11-2`；年份范围的起始值不能大于结束值。

日和周字段额外支持 `?`，用于表达“该字段不指定”。工具会通过“按日期 / 按星期”开关自动处理：

- 按日期：表达式形如 `秒 分 时 日 月 ? 年`。
- 按星期：表达式形如 `秒 分 时 ? 月 周 年`。

## 常用示例

| 场景                 | 表达式             | 描述                                            |
| -------------------- | ------------------ | ----------------------------------------------- |
| 每天 09:00 执行      | `0 0 9 * * ? *`    | 每年每月每日 09:00:00 执行                      |
| 每 5 分钟执行        | `0 0/5 * * * ? *`  | 每年每月每日 每小时、从0分开始每5分钟、0秒 执行 |
| 工作日 09:30 执行    | `0 30 9 ? * 2-6 *` | 每年每月周一至周五 09:30:00 执行                |
| 每月 1 日 00:00 执行 | `0 0 0 1 * ? *`    | 每年每月第1日 00:00:00 执行                     |
| 每年 1 月 1 日执行   | `0 0 0 1 1 ? *`    | 每年1月第1日 00:00:00 执行                      |

## 解析规则

- 输入 7 字段表达式时，会按 `秒 分 时 日 月 周 年` 解析。
- 输入 6 字段表达式时，会按 `秒 分 时 日 月 周` 解析，并自动补全年字段 `*`。
- 日字段和周字段必须有且只有一个使用 `?`。
- 解析失败时会给出中文错误提示，例如字段数量错误、字段越界、格式非法等。

## 当前限制

- 不支持 `cron(...)` 或 `rate(...)` 包裹格式。
- 不支持 `L`、`W`、`#` 等高级 Quartz 特殊符号。
- 不做未来执行时间预览。
- 不做 Kubernetes、GitHub Actions、AWS EventBridge、Spring 等平台导出。
